# Gestor de Tareas Personal 📝

Este es un proyecto web desarrollado con JavaScript que permite gestionar tareas de forma eficiente y organizada. Podés crear, editar, leer, borrar y cambiar el estado de cada tarea.

---

## ✨ Funcionalidades

- ✅ **Crear tareas** con un título y descripción.
- 🔁 **Editar tareas** ya creadas para actualizar contenido.
- 📖 **Leer tareas** con sus detalles completos.
- 🗑️ **Eliminar tareas** individualmente.
- 🔄 **Cambiar estado** de la tarea entre:
  - `Creada`
  - `En proceso`
  - `Terminada`
- 🕓 Registro de:
  - **Fecha y hora de creación**
  - **Fecha y hora de última modificación**
---

## 💡 Objetivo

Construir una aplicación práctica que funcione como un **organizador de tareas personal**, fomentando el uso de lógica de programación y manipulación del DOM, mientras se aplica el almacenamiento local de datos.
